自动记录

让电脑自己记：检测程序记什么、怎么清洗、规则怎么归类，以及今天自动记下了什么。 要你确认的建议、AI 的报告和规则草稿在 AI助理页。

活动检测设置

桌面检测程序（ai-detector）上传前怎么清洗窗口标题、离开怎么算。按设备分开设； 检测程序每轮（最多 5 分钟）拉一次，改了下一轮生效。

这个按钮只做两件事：检测 ActivityWatch 是否在运行，没在运行就重启它。不会重启检测程序，也不会重启面板。

检测程序没在运行，按钮无效。请在电脑上启动检测程序（ai-detector autostart install 可设开机自启）。
