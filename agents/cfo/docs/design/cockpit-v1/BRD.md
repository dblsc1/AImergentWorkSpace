# BRD · 时间驾驶舱前端升级（cockpit-v1）

- 日期：2026-08-08 · 属主：CFO · 状态：**待用户批准**
- 配套：`PRD.md`（产品需求）、`index.html`（设计稿 v1，已批）、`tokens.css`（token 种子）

## 1. 一句话

把四页驾驶舱（登录 / 计时 / 任务 / 甘特）升级为**统一亮暗双主题的仪表盘**，
补上**任务级排期与依赖箭头**，尽快上线四模块联动。

## 2. 现状问题（为什么现在做）

| # | 问题 | 证据 |
|---|---|---|
| P1 | 暗底暗字，对比度不达标 | 用户定性「简直是灾难」；无机械校验，靠人眼当验收工具 |
| P2 | 风格半统一 | table/gantt/login 一套变量靠逐值复制，ring 自成一套已漂移 |
| P3 | 四页无联动 | 顶栏只有导航；计时状态离开 ring 页不可见；页面间无跳转路径 |
| P4 | 计时页割裂 | 贡献圆环与计时控件是两块各自刷新的区域 |
| P5 | 无依赖表达 | 任务之间的先后关系没有任何承载 |
| P6 | 换主题色要改四个仓 | 变量逐值复制的直接后果 |

## 3. 目标与成功指标（可度量）

| 目标 | 指标（验收时机械可判） |
|---|---|
| G1 上线联动 | LAN 上手机/平板/桌面可用；三窗并排（390px 容器）不横滚、顶栏不折行 |
| G2 对比度达标 | 契约对比度表全组合 ≥4.5:1（正文）/ ≥3:1（大字与图形），脚本校验全绿，**每个预设主题色各跑一遍** |
| G3 主题可换 | 开发级：换色 = 只改 tokens 一处；用户级：顶栏选预设主题色，localStorage 记住，多窗即时同步 |
| G4 任务级依赖 | 甘特上可拖线建立、可点选删除、排期冲突琥珀警示（不阻止、不自动排程） |
| G5 质量底线 | 各前端 E2E 零 console 错误保持；`</body>` 锚点唯一保持；tokens 兜底块 diff 契约表脚本过 |

## 4. 范围

**做**：设计系统落地（方案 C）、顶栏 v2、四页换皮与布局重排、跨页联动、
ring 取消按钮、任务计划期字段、任务级依赖（数据模型 + 甘特箭头 + 拖线编辑）、预设主题色选择器。

**不做（明确出局）**：自动排程、关键路径、garden 页、原生 App、提醒通知、
多用户/权限、依赖的资源负载视图。

## 5. 干系人与决策记录

- 用户（唯一使用者，人类裁决）：已拍板——设备三端+多窗、亮暗双主题、方案 C、
  任务级依赖、甘特拖线、琥珀警示不阻止、换色两级都要、留 vis-timeline 不换引擎。
- CFO：契约、协调、验收；不写模块业务代码。
- 五模块 agent（nginx-docker / ring / table / gantt / auth）+ nexus-core（后端增量）。
- consulter：流程与架构独立监督。

## 6. 约束

- 治理铁律全套适用：契约先改后动代码（铁律 4）、写边界（前端不涉足后端）、
  留痕与 canonical report、测试分层。
- **events 台账只读不动**（人类既有裁决）：本项目所有后端增量都在 planner（可变花名册）
  与只读投影/读端，不碰事件写路径。
- 离线优先：一切第三方库 vendor 入仓 + SHA256（铁律 22），禁 CDN。
- 许可：MIT / Apache-2.0 系（vis-timeline 双许可、timeline-arrows MIT 已核）；禁 GPL 传染与商业 PRO 档。
- 密钥零新增；会话机制不动。

## 7. 里程碑与成本（agent 轮次；用户订阅下瓶颈是验证轮次不是劳力）

| 里程碑 | 内容 | 估计 |
|---|---|---|
| M1 契约先行 | design-tokens-v1 契约、nginx-docker v0.6、nexus-core 契约任务排期+依赖增量 | 0.5 晚 |
| M2 皮肤与联动 | tokens.css + 顶栏 v2 + 四页换皮/重排 + 预设主题色（五模块并行） | 1 晚 |
| M3 后端增量 | Task.plan / Task.dependsOn + 校验（存在/禁自指/禁环/删除 409）+ 任务级日投影读端 + 测试 | 1 晚 |
| M4 甘特任务层 | 嵌套分组任务条 + timeline-arrows 接线 + 拖线编辑 + 琥珀警示 | 1–2 晚 |
| M5 收口 | E2E 扩展、对比度/禁裸 hex 判据、全站验收 | 0.5 晚 |

总计 **8–12 轮 / 约 4–5 晚**。M2 与 M3 可并行。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| timeline-arrows 与 vis-timeline 8.5 兼容未验 | M4 开工第一件事冒烟；不合就 fork（本体几百行，MIT） |
| 拖线在触屏上难操作 | 长按出手柄；同时保留编辑弹窗「前置任务」多选作兜底路径（可达性要求，不是可选项） |

| 预设主题色使对比度组合翻倍 | 对比度校验按「预设 × 明暗」矩阵全跑，契约表带满预设 |
