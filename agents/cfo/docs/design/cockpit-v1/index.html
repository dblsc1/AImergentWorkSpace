0 · 设计语言：仪表盘的诚实

这套系统的底层信念是「事实台账不说谎」——设计语言照搬这个信念： 计划紫永远表示意图（planner 台账），事实青永远表示已发生（events 台账）。 每个时间实体都用「双轨」呈现：上轨紫是计划，下轨青是事实，对不上一眼就看出来。 所有「开始计时」类动作用事实青——按下去就是在产生事实。 每种颜色实测 WCAG 对比度标在下面，落地后有脚本按这张表机械核验，暗底暗字这类灾难从此进不了仓。

顶栏是四页「逻辑联系」的物理载体：页签导航 + 全站常显的录制状态 + 主题开关。

行为规格
  • 录制胶囊读 /__cockpit/current（现有 10s 轮询不变）；先判 degraded 再读 running——降级时胶囊变琥珀「状态未知」，不许把后端挂了显示成「没在计时」。
  • 点胶囊 → 跳计时页。窄窗（<560px 容器）只留点 + 时间，页签缩短——三分窗并排时顶栏不折行。

  • 退出按钮 = POST /api/auth/logout；登录页不注入顶栏（现状判据保持）。

3 · 计时 —— 仪表圆环（全站签名件）

一只表两份职责：环上分段 = 今天各任务已录的事实（同色深浅，深 = 当前任务）， 表芯 = 正在走的计时。旧版「贡献圆环」和计时控件合并成一件仪器，不再是两块各自刷新的区域。

行为规格
  • 未计时：表芯显示「今天 · 48 分」+ 大按钮「开始计时」；选择器两级（项目 → 任务），零任务项目显示灰提示行（已实现，保留）。
  • 录制中：选择器锁定；「停止并记录」走 timer.stop，「取消，不记录」走 timer/cancel（后端已上线，本轮补按钮）。
  • 表芯秒跳本地自增；环分段只在数据真变时重绘（本轮修好的行为，落到新 UI 保持）。
  • 环分段动画只在首次载入长出一次，350ms；prefers-reduced-motion 时直接就位。
  • 宽容器（≥640px）左表右控两栏；窄窗上下叠，环缩到 78cqw。
