# 2026-08-02 · CFO · 我把口令写进了公开仓

写反口令泄露的判据时，在注释里拿真实口令举例。文件是公开仓的，已 push。

当前树已清。**历史里删不掉。**

判据没拦住是**设计如此**：它认赋值形态，散文裸提及不管，也不该管 ——
要管就得把口令写进判据本身。所以这不是判据的缺陷，是我的。
**而这一类天然只有人守，没有机器兜底。**

「字面量类」第四次复发，前三次都在私仓或被机器拦下，这次两条都破。

**直接后果**：轮换从「用户的选择、不紧急」变成「应当做」。
我之前给的「泄露只在 private 仓」的前提不成立了。
