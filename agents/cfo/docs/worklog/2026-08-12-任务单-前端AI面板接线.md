## 交付

1. **点按钮 → 开 SSE**，边收边渲染。事件类型见上（`thinking`/`action_plan`/`executed`/`proposal`/`done`）。
   **别等 done 才画**——流式的全部意义就是别白屏等十几秒（F-AI-5）。
2. **低风险已执行的**：显示做了什么，刷新待办区/树，让 🤖 角标自然出现。
3. **高风险提议**：逐条列出（`kind`=move/reschedule/delete + 目标 + 理由），
   **每条一个「确认」按钮**。确认后由**前端正常路径**调既有 CRUD 执行（`actor=human`）。
   ⚠️ **这是安全设计的一部分**：AI 没有执行高风险写的路径，执行的是人的手。别绕过。
4. **降级**：AI 服务挂/超时 → 明确提示「AI 规划暂不可用」，**待办区规则层照常**（G3）。
   401 → 提示重新登录，别把 HTML 当事件流解析。
5. 目标输入：给个输入框让用户填 goal（默认值可给"帮我理清收件箱并排下一步"）。
