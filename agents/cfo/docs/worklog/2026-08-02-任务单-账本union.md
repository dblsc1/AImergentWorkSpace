# 2026-08-02 · CFO 自派 · 账本 JSONL 声明 union merge

## 目标

`logs/ledger.jsonl` 是 append-only 账本。两个角色（CFO / consulter）同日各推一次，
rebase 时被判成同行冲突，冲突标记混进 JSONL —— 那一刻文件已不是合法 JSONL。
声明 `merge=union`，让「两边都要」成为默认行为而不是每次人工决定。

## 验收标准

- 根仓与各模块（含 `code/_template/`，新模块自动继承）都有 `.gitattributes`
- 根级新文件必须同时登记进 `.gitignore` 白名单（本仓白名单会静默吞掉未登记文件）
- 沙箱实弹：两侧各追加一行，merge 无冲突且两行都在

## 可触碰目录

`.gitattributes`、`.gitignore`、`code/_template/`、`agents/cfo/docs/`、`logs/`、`scripts/`
