## 两处误报，各自的类

**① 右值没剥容器闭合符**

```
json={"password": password},
```

右值剥了 `,` `;` 却没剥 `}` `)` `]`，于是算成 `password}` ——
比占位符白名单差**一个字符**。类：任何「单行 dict / 调用、右值是变量、闭括号同行」。

**② 右值是标识符不是值**

```
PASSWORD_ENV_VAR = "COCKPIT_TEST_PASSWORD"
```

存的是变量**名**。通则：**真凭据不会是 SCREAMING_SNAKE_CASE** ——
右值整体匹配 `[A-Z][A-Z0-9_]{2,}` 就当标识符放行。

这条比逐个加白名单强：它认的是「右值看起来像代码里的名字」这个形状。

没造成损失，但形状值得记：**`cd $T && ...` 里的 `cd` 失败了，后面的命令照常在原地跑。**
