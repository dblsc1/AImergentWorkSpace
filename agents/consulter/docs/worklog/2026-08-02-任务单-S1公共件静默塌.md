## 目标

着陆检查单是全项目唯一的硬闸门，而它能被**一个文件缺失**变成橡皮图章，
且界面与真验过一模一样。三段病根一并修，且修的是**类**不是十二个实例。

## 可判定的验收标准

1. 删掉 `scripts/lib/paths.sh` 后**逐条**跑全部 check：凡源码里用到它的，
   退出码必须非 0；**任何一条静默退 0 就算失败**（不是抽样一条）。
2. 主脚本侧独立成一层：check 的输出里出现**解释器级错误**
   （`: line N: … command not found / No such file or directory / unbound variable / syntax error`）
   时，即使退 0 也不许判成 pass。
3. 反向验证证明**两层各自有效**：只拆层①、只拆层②，各自都要能看见红。
4. 结构断言：`scripts/` 下任何脚本 source 公共件而没有失败守卫 = 红
   （挡住下一个新写的 check 再次引入同一形状）。
5. `selftest.sh` 与 `mission_complete.sh` 常态全绿，无新增误报。
