# 2026-08-02 · consulter · 判例库补三条（S1 轮付的学费）

`agents/consulter/记忆.md` 追加三条，全部来自本轮反向验证的真实点火：

1. **验守卫要验「是不是它造成的」** —— 只断言退出码非 0 时，
   一个碰巧同向的旁因（05 本来就因缺路签而红）就能让断言恒绿。
   推论：全仓守卫必须用同一句措辞，否则断言要认两套规矩。
2. **两层防线的分工是「现在」和「将来」，不是冗余** ——
   层①管已知实例、层②管未知的将来、层③管下一个人照抄什么；
   反向验证必须逐层拆，只做一发证明不了任何一层。
3. **自己写的断言也会开洞**（第三、四例）——
   grep 漏掉变量形式的 source；双引号里的反引号变成命令替换。

## 为什么进判例库

第 1 条是**方法论级**的：它适用于本仓每一条「加防御 + 断言它有效」的组合，
不限于 S1。第 2 条把「修类」这个抽象要求落成了可执行的分层。
第 3 条是同一个母题的第三、四次实证 —— **三轮下来，每一轮都是反向验证
抓出验证者自己的问题，没有一轮例外。**
