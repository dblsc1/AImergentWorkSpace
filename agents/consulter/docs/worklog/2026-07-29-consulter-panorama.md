# 工作空间全景文档

人类要一份「角色分工 + 现行规矩 + 各种细节」的文档，一份给 Fable 冷启动、一份自己看项目全貌。
做成同一份：`agents/reference/工作空间全景.md`。

**和已有文档的分工写在开头**，免得又多一个事实源：
`AGENTS.md` 是判案依据（条文），全景是**地形图**（谁在哪、为什么这么设计）；
冲突时以 `AGENTS.md` 与 `CONSTITUTION.md` 为准，全景改到与它们一致。

十一节：解决什么问题 / 角色与分工 / 完整流程 / 三层闸门 / 着陆检查项 /
文档纪律 / 留痕四件套 / 23 条铁律 / **已付过学费的坑** / 目录与工具 / 当前项目状态。

内容全部取自实测，不凭记忆：铁律标题、检查项判据、模块与远端、契约行数
都是从仓里 grep 出来的。第十一节写了当前唯一路障（CFO 四模块 pre-commit 从未装上）。

第九节「已付过学费的坑」是我认为最该先读的一节 —— 它不是规矩，是**规矩的价签**。
没有价签的规矩，人第一次嫌麻烦就绕过去了。
