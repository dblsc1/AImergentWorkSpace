## 目标

人类 2026-08-02 裁决：**C1（单文件行数）只管源码文件，散文不算**，`.md` 不在行数限制内。
理由（写进裁决台账的人类口径）：500 行的约束本意是**逼你拆职责**，那是代码的道理；
长文档拆开反而伤可读性。

把这条裁决落成：宪法条文 + 台账一条 + 机械判据 + 双向断言。

## 验收标准

1. `agents/CONSTITUTION.md` 的 C1 措辞明确**只管源码文件**；台账新增一条（下一个可用编号），
   日期 2026-08-02、裁决人＝人类，并写清与 D12 的关系（**D12 定分档，本条定适用范围，不冲突**）。
2. `scripts/gates/run-gates.sh` 的行数判据有**扩展名白名单**，**显式列举、可增删、只此一处事实源**。
   `.md` `.txt` `.jsonl` 不看；`.sh .py .js .ts .html .css .json .yaml .toml` 要看。
   **`.sh` 必须在表里**（`selftest.sh` 那次拆分正是这条判据该管的）。
3. `selftest` 断言同批改，**两个方向都点火**：
   「`.md` 超 1000 行不再红」**并且**「`.sh` 超 1000 行照样红」。只验一半不算过。
4. 反向验证的真实退出码写进 worklog。
