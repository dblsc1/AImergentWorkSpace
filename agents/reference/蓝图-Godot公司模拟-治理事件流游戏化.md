# 蓝图：Godot 公司模拟——治理事件流的游戏化渲染

> 状态：**待 X_structure 就绪后开干**（用户裁定 2026-08-03），本文是开工蓝图，排铲归用户。
> 配套阅读：`科普定位-新手第一个多agent架构.md` §2（本方案 = 其功能 1/2/3/8/10 的统一渲染载体）。

## 一句话

把治理框架的事件流渲染成一家像素风编程公司：agent 入职搬椅子、领写区令牌进仓库、
互相对话、门禁红灯拉警报、commit 打包、push 出货——**「看 AI 公司干活」本身就是可传播内容**。

## 为什么可行：最难的一半已经存在

游戏渲染需要结构化事件流，本框架天生是事件源架构。普通项目做可视化 80% 工作量在
「先把系统改成能吐事件」；这里 diary.jsonl / comm.jsonl / ledger.jsonl / lease 文件 /
门禁输出已经在吐。Godot 只是消费者。先例：Gource 证明「事件流变动画」成立且受欢迎；
本方案多出治理语义，无人做过。

## 事件 → 动画映射

| 事件源 | 渲染 |
|---|---|
| mission_start 发路签 | 小人领令牌，围挡门开 |
| new_instance.sh 开实例 | 搬椅子入职 |
| comm.jsonl append | 对话气泡 |
| 门禁红 | 车间警报灯，拦在门口 |
| commit | 打包裹上架 |
| push | 卡车出货 |
| 打回 | 包裹退回工位 |
| 逃生口（ledger.jsonl） | 走侧门 + 账本记一笔 |
| 停线旗（STOPLINE） | 全场熄灯 |
| 越区写入被拦 | 撞围挡弹回 |

代码库 = 仓库区（understand-anything 生成布局），写区 = 围挡，令牌 = 进门钥匙。

## 架构：adapter 层隔离

```
diary/comm/ledger/lease/门禁stdout → [adapter 脚本] → events.jsonl（归一化契约）→ Godot 渲染器
```

渲染器是框架的**消费方**，只认 events.jsonl 契约，不直读散装文件——框架演进不哑火
（契约至上铁律吃自己狗粮；渲染器失同步与 doc-sync 是同一形状的病）。

## 分阶段与估算（Claude 20x + Codex Pro，瓶颈是人的验收带宽不是 token）

| 阶段 | 内容 | agent 任务量 | 日历 | 人的精力 |
|---|---|---|---|---|
| P0 事件 adapter | 归一化 events.jsonl + 断言 | 2-3 任务 | 1-2 天 | 2-3h（schema 裁决） |
| P1 回放 MVP | Godot 4 俯视角、6 种事件动画、回放模式 | 5-10 任务 | 1-2 周业余 | 每天 0.5-1.5h 视觉验收 |
| 首发 demo 视频 | 真实判例事件流 → 90 秒回放录屏 | 1-2 任务 | +2-3 天 | 半天 |
| P2 直播模式 | tail 实时事件流 | 2-3 任务 | +1 周 | 少 |
| P3 产品级 | 布局自动生成、web 导出、正经美术 | 开放式 | 月级 | 看首发反响再投 |

**唯一承诺的里程碑：首发视频，3-4 个周末。**

## 三个关键决策（已定，开工不再议）

1. **回放优先，直播靠后**：回放确定性（同一 events.jsonl 永远同画面），agent 可自测；
   回放文件 = 课程集数，先做的恰好是卖课要的。直播全是时序毛边，P2 再碰。
2. **视觉验收半自动**：Godot 4 headless 出帧（`--write-movie`），agent 截图自读自查，
   人只看筛过的关键帧。
3. **美术零投入**：Kenney CC0 像素资产包，第一版一分钱不花，像素风即风格。

## MVP 验收标准（硬边界，防 scope creep）

> 一条真实判例的事件流，90 秒回放，六种事件（入职/领签/对话/红灯/打包/出货）全出现，录屏可发。

凡不在这句话里的（3D、换装、寻路、音效、多层楼）一律进 backlog，首发后按反响排。

## P0 开工前的裁决清单（要用户拍板，D 级决策）

1. **事件 envelope 必填字段**：ts / event / actor / role / module / branch / head / payload
   ——哪些必填、payload 各事件型如何约束。
2. **时间源归一**：多 checkout 时钟交错怎么排序（2026-08-02 rebase 实证：两 checkout
   在同一分支交错工作）。
3. **去重口径**：同一事实在 diary 与门禁 stdout 双记时以谁为准（三源对账的口径决定）。
4. **回放文件粒度**：一任务一文件 vs 一天一文件。
5. **脱敏**：路径、commit message、agent 名是否原样进回放——课程要公开，先定规则。
6. **adapter 落点**：脚本放 `scripts/` 哪个子目录；events.jsonl 入仓跟踪还是可再生不入仓
   （两头必须占一头，铁律：克隆即缺件不允许）。

## 分档路由（吃自己狗粮）

- claude 强档：事件 schema、adapter 架构、Godot 场景结构

## 风险

- **scope creep**（最大，兴奋期尤甚）：MVP 验收标准一句话即全部边界。
- **渲染器消费契约失同步**：adapter 层 + events.jsonl schema 断言（selftest 一条）兜底。
- Godot web 导出包重（~30MB+）：首发走录屏视频不受影响；在线产品化时再评 PixiJS 替代，
  adapter 契约不变所以不锁死。
