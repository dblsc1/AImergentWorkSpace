# 文档地图

> 单一导航入口。文档或目录变化时，同一逻辑变更内同步本表。

| 想了解 / 改什么 | 唯一事实源 | 说明 |
|---|---|---|
| 全项目铁律、边界、工作模式 | `AGENTS.md` | 级联根，下层不得覆盖 |
| 架构设计与原因 | `agents/reference/1 structure/README.md` | 权威长文说明 |
| 目录速览与落地占位 | `agents/reference/manual/README.md` | 新人入口 |
| 新模块 / 新项目流程 | `agents/reference/新模块与新项目开设指南.md` | 轻量/完整治理两种模式 |
| 跨项目通用踩坑与纪律 | `agents/reference/manual/通用经验教训.md` | 报告门禁/命令目录/部署/里程碑经验 |
| 新模块默认结构 | `code/_template/` | 唯一事实源 |
| 角色通用方法 | `agents/roles/{arbiter,backend,frontend,reviewagent}.md` | 模块角色卡只做薄引用 |
| 子代理编排 | `agents/roles/orchestration.md` | 续用上下文、分层交接与留痕 |
| `report.json` 格式与 canonical path | `agents/roles/report-schema.md` | embedded-self-v2 与 exact review target |
| 项目级 arbiter / consulter | `agents/cfo/{arbiter,consulter}/AGENTS.md` | 仅角色卡，无历史 findings |
| CI、hooks、gates、合并门 | `scripts/README.md` | 脚本与 env 参数说明 |
| 模块对外行为 | `<module>/module_docs/contract.md` | 对外契约唯一事实 |
| 模块特有规则与自检 | `<module>/module_docs/rules.md` | 工作模式、技术栈、确定命令 |

## 文档四件套（完整治理）

- worklog：回顾过去的叙事。
- report.json：当下 agent 间交接。
- diary/jsonl：机器 append-only 事件流水，由 `scripts/log_event.sh` 生成。
- handoff：面向未来接手者，由模块 arbiter 独占维护。
