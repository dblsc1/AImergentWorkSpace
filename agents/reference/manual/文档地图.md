# 文档地图

> 本文件是导航。**结构变了必须同步这里**（铁律 11），
> 且 `scripts/checks/_common/60-doc-paths-exist.sh` 会核验下面每个路径真实存在。

## 顶层四分区

| 分区 | 放什么 |
|---|---|
| `agents/` | AI 的规范与留痕：角色卡、CFO、项目级审核、参考文档 |
| `code/` | 代码：模块骨架 + 各模块 |
| `logs/` | 日志区：索引、机器流水、控制台 |
| `scripts/` | 一切可执行：脚手、门禁、hooks、检查项 |

根目录只有三份文件：`AGENTS.md`（规范根，唯一必读）、`CONSTITUTION.md`（项目加严 + 裁决台账）、`README.md`。

## 规范（读这几份就够开工）

| 文件 | 作用 |
|---|---|
| `agents/AGENTS.md` | 通用铁律全集、角色写边界、协作流程、文档体系（根 `AGENTS.md`/`CLAUDE.md` 是一行指针） |
| `agents/CONSTITUTION.md` | 本项目加严条款 + **§4.1 已批准但未落进契约的裁决**（非空时必须先清空） |
| `agents/roles/` | **四份角色卡**：`arbiter` / `programmer` / `programmer_reviewer` / `module_reviewer`（写边界留空，由 `scripts/new_agent.sh` 填实） |
| `agents/protocol/` | 协议（不是角色）：`report-schema.md` 报告格式、`orchestration.md` 编排机制、`supervision.md` **监督矩阵（谁审谁的唯一事实源）** |
| `<模块>/AGENTS.md` | **模块级提示词事实源**，含技术栈、自检门、流程、**已知坑**（踩坑直接写这，不另开文档） |
| `agents/cfo/doc-map.tsv` | **长期文档 ↔ 代码区域 的治理关系**（CFO 维护，随项目不断变化）——改了哪片代码、哪些长期文档必须跟着改，由它决定 |
| `.env.example` | 全部 18 个 `AIMERGENT_*` 变量的唯一集中清单 |
| `agents/reference/HANDOFF.md` | **项目总目标**（要做成什么，指导性可改）—— 与铁律（怎么做才算数）分工 |
| `agents/reference/新模块与新项目开设指南.md` | 开模块、开项目、根仓开工、8 条验收清单 |

## 留痕：四件套，各一个写属主

| 文档 | 位置 | 写属主 | 时间维度 |
|---|---|---|---|
| 任务单 | `codeagent/<执行角色>/docs/worklog/` | arbiter 开单写进执行者目录 | 任务开始 |
| worklog | `codeagent/<角色>/docs/worklog/` | 各角色写自己的 | 回顾过去 |
| report.json | 见下方路径表 | 各角色写自己那份 | 当下交接 |
| diary | `codeagent/<角色>/docs/WorkIterationDiary/` | 机器，只用 `scripts/log_event.sh` | 机器流水 |
| handoff | `<模块>/module_docs/handoff.md` | **arbiter 独占** | 面向未来接手 |

**留痕保持分散在各角色目录下**（人类裁决），`logs/INDEX.md` 由 `scripts/reindex.sh` 生成用于导航。

canonical report 路径表见 `agents/protocol/report-schema.md`。

## 脚本

| 脚本 | 干什么 |
|---|---|
| `scripts/aim` | **单一入口**：无参数打印整条生命周期与每步该跑什么，带参数代跑 |
| `scripts/new_module.sh` | 一个参数建模块：骨架→清占位→装门禁→生成三个角色→初始 commit→开分支 |
| `scripts/new_agent.sh` | 建角色实例：复制角色卡→填实可读可写→写 `.claude/agents/<角色>.md`（含出生考卷） |
| `scripts/dispatch.sh` | 生成派单提示词（角色卡首行 + 版本哈希 + 开卷判据） |
| `scripts/run_agent.sh` | **用 shell 起独立 Claude 进程执行角色任务**，绕开子代理嵌套限制；`--resume` 续用 |
| `scripts/exam.sh` | 开工考试（只考通用流程），不过退回 arbiter 重派 |
| `scripts/mission_complete.sh` | 完工检测硬闸门，`--list` 输出全部判据 |
| `scripts/checks/` | 检查项三层级联（_common/角色/模块），一条一个文件，可增删改查 |
| `scripts/reindex.sh` | 生成 `logs/INDEX.md` |
| `scripts/console.sh` | 生成 `logs/console.json`，配 `logs/console.html` |
| `scripts/selftest.sh` | 门禁有效性自测（断言全集，条数见运行输出） |
| `scripts/install-gates.sh` | 装门禁与 hooks，传 `.` 即给根仓自己装 |
| `scripts/arbiter-push.sh` / `scripts/merge-to-integration.sh` | 唯一合法的推送 / 合并路径 |
